HOW TO ADD YOUR PHOTOS
======================

Drop your image files into THIS folder using the exact filenames below.
The website picks them up automatically — no code changes needed.
Until a file is here, the site shows a yellow "Upload →" placeholder
in that spot telling you the filename and size.

Use JPG or PNG. Match the size (width x height in pixels) as closely
as you can so nothing looks stretched.

------------------------
hero.jpg              900 x 1040   Big main photo in the top section
                                   (you on a job / a clean panel / your van)

recent-work.jpg       720 x 720    "Why us" section photo (finished work)

                                   (screenshot a Google Map of Dearborn)

You can crop them square for free at https://squoosh.app or in Photos.
